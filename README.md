# Forage: Well's Fargo Software Engineering Simulation
This is the second task of the above-mentioned position roject.
The project's problem is as follows: "Implement your data model through actual code so it can be used for the new system."
The data model was created in Task 1, and is attached for reference.
Provided was the project scaffold on which the data model would be implemented. It's a Maven project with programming in Java, Spring Boot & JPA (Java Persistence API).
